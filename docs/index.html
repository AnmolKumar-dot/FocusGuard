Install in 5 steps

FocusGuard is not on the Play Store, so Android asks a few extra questions.

  1. Download the APKTap Download APK, then open Assets and tap the .apk file.
  2. Allow the installAndroid asks to allow installs from your browser. Play Protect may show a warning because the app is not from the Play Store: tap More details, then Install anyway.
  3. Turn on AccessibilityOpen the app, go to Blocks, tap Fix now and switch on FocusGuard. This is how it knows which app is open.
  4. If the switch is greyed out (Android 13+)Phone Settings → Apps → FocusGuard → three-dot menu → Allow restricted settings, then try again.
  5. Keep it runningSet battery to Unrestricted for FocusGuard, and allow Usage access from the Usage tab for screen time and limits.

Questions

 

Is it really free?

Yes. No ads, no account, no subscription, no in-app purchases. The source code is public under the MIT licence.

What does it do with my data?

Nothing leaves your phone. The Accessibility service checks what is on screen only while blocking is on, and never records it. The internet is used only for the optional YouTube channel search. Read the privacy policy.

Why does it need Accessibility?

It is the only way a normal app can see which app or website is open in order to block it, and to spot Reels and Shorts screens. Without it, blocking cannot work.

Why does Play Protect warn me?

Because the app does not come from the Play Store and uses the Accessibility service. That is expected for apps installed from outside the store. You can check the code yourself on GitHub.

It stopped blocking Reels or Shorts

Instagram and YouTube sometimes change their screens, which can break detection until the app is updated. Please report it with your phone model, Android version and the app version.

How do I update?

Download the newest APK from the releases page and install it over the old one. Your settings are kept. Use Settings → Save a backup first if you want a safety copy.

Does it work on iPhone?

No, Android only. iOS does not allow this kind of blocking.
